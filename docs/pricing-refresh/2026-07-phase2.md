# Pricing refresh — 2026-07 (Phase 2/3: network & FSx)

Date: 2026-07-28

Scope: `elastic-ip`, `load-balancer`, `nat-gateway`, `vpn-connection`,
`transit-gateway-attachment`, `kinesis-shard`, `fsx-windows`, `fsx-lustre`,
`fsx-ontap`, `fsx-openzfs` in
`libs/cloud-cost/infrastructure/aws-adapter/src/pricing/prices.json`.

Sourcing note: outbound access to `aws.amazon.com` is blocked by this
environment's network policy (WebFetch/curl both get a 403 at the proxy
layer), so official AWS pricing pages could not be fetched directly.
Verification relied on WebSearch results, several of which quote or closely
paraphrase the official AWS pricing pages' figures. Only changes backed by
multiple consistent sources describing a specific, dated AWS pricing policy
were applied; everything else was left unchanged per the "never guess" rule.

## Keys changed

- `elastic-ip` in `eu-west-1`, `eu-central-1`, `ap-southeast-1`,
  `ap-northeast-1`: **3.960 -> 3.600** (region-specific values corrected to
  match the flat, region-uniform $0.005/hour public IPv4 / Elastic IP charge
  that AWS has applied globally across all commercial regions since the
  February 2024 pricing change — confirmed by multiple independent sources
  describing that announcement, and consistent with the `default`,
  `us-east-1`, and `us-west-2` tables, which already used 3.600).

`pricesAsOf` bumped to `2026-07` to reflect this verification pass.
